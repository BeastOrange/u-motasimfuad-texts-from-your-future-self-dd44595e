# Texts From Your Future Self

## Description
This repository contains an entry for the make.fun bounty **"Texts From Your Future Self"** (`u-motasimfuad-texts-from-your-future-self-dd44595e`).

The entry is a single urgent, standalone text message sent back from the future:

> *"Do NOT agree to watch your sister's ferret for 'just the weekend.' It is 2031, he has power of attorney, and I am not allowed on the good sofa."*

### Why It Works
- **Instant Recognition & No Setup**: Starts with the classic casual favor that sounds harmless ("just the weekend").
- **Escalation & Twist**: Fast-forwards to 2031 where the ferret has somehow secured legal dominance ("power of attorney").
- **Grounded Punchline**: Drops from absurdity straight into domestic indignity ("not allowed on the good sofa").
- **Concise**: Exactly 143 characters—well within the 200-character ceiling, packing high comedic impact per character.

## Run it
Run the entry with Python 3:

```bash
python3 main.py
```

Running the command prints the text message to stdout and writes the exact single line to `output/entry.txt` (as well as `/output/entry.txt` if available in the execution environment).
